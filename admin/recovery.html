Recovery procedure

Use a proper owner-recovery flow rather than hidden keywords or undocumented backdoors. The goal is to keep the site access controlled and auditable.

  1. Use the verified owner email to reset the password from the admin system.
  2. Keep a secondary backup admin account with separate credentials.
  3. Store the password in a reputable password manager such as Bitwarden or 1Password.
  4. Enable MFA or 2FA on the admin account.
  5. Keep a printed or encrypted backup recovery code in a secure location.
Do not rely on public email keywords or hidden form triggers for admin access. Those are not secure and are difficult to audit.
