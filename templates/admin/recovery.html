Recovery

Owner recovery checklist

Use this secure procedure if the admin credentials are lost, suspected to be compromised, or need to be rotated.

  1. Verify ownership through the official college contact channels and confirm the site admin is the rightful owner.
  2. Update the admin password in the server environment, not in the repository or in public files.
  3. Regenerate the site secret key and rotate any related credentials used for maintenance access.
  4. Review the server logs and last successful login times for suspicious access.
  5. Keep the private admin URL unlisted and restrict it to trusted devices only.
Recommended: use a strong password manager and rotate credentials every few months.
